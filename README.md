# ybi-
# Diabetes Prediction using Logistic Regression

## Overview

This project demonstrates Binary Classification using Machine Learning to predict whether a patient has diabetes based on several medical attributes. The model is built using Logistic Regression from Scikit-learn.

## Dataset

The dataset used is the Pima Indians Diabetes Dataset.

Features include:

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age

Target:

- Diabetes (0 = No Diabetes, 1 = Diabetes)
